# v0.2.0 — 2026-09-30

## Highlights

- Added named YouTube channel profiles. Use `profile list` to view saved profiles and `--profile <name>` to select the profile for a command.
- Added ready-to-use `katy404` and `armigon` profiles while keeping support for the legacy `profile.json` setup.
- Bound the local OAuth callback to IPv4 loopback (`127.0.0.1`) for more reliable authorization.

## Documentation

- Updated setup and operations guides for profile-based use.
- Clarified the uploader's vision and roadmap.
